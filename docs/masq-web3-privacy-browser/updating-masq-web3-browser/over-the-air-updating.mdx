# Over-the-Air Updating

## OTA Updates

Turn off MASQ then select Update MASQ in the top bar

<figure><img src="/img/assets/image-49.png" alt=""  /><figcaption><p>UPDATE Button Turns Red when available</p></figcaption></figure>

Select the Download button to start the update process

<figure><img src="/img/assets/image-50.png" alt=""  /><figcaption></figcaption></figure>

Once the download is complete, select OK to complete the update

<figure><img src="/img/assets/image-39.png" alt=""  /><figcaption></figcaption></figure>

MASQ will close and update

![](/img/assets/image-23.png)

Once the update is complete, MASQ will start and prompt to enter your password

<figure><img src="/img/assets/image-46.png" alt=""  /><figcaption></figcaption></figure>

Once you enter your password and unlock the app, you can start MASQ and **enjoy the new features from your OTA update!**

<figure><img src="/img/assets/image-32.png" alt=""  /><figcaption></figcaption></figure>
