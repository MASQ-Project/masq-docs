# Checking MASQ Browser Version

You may want to check if you are running the latest version of MASQ Browser, or need to report issues or troubleshoot with the MASQ User Support team in our [Discord](https://discord.gg/cdUsjBQrgq) - use the official Support Ticket channel or direct communication. DO NOT ANSWER ANY DM!

You can find the Version number on the bottom right of the General Settings page
